# Student OS Design Direction

Student OS is a calm personal command center for developers and learners. Its visual language combines a pale lavender workspace, deep ink typography, a disciplined indigo-violet accent, and structured panels that make progress, reflection, and learning feel intentional rather than noisy.

The verification pass confirmed that the authenticated workspace renders with a stable sidebar, clear page hierarchy, responsive form layouts, dedicated empty states, and true-data-oriented copy. Continue using a single signature purple for brand, active navigation, primary actions, and progress signals. Keep supporting surfaces quiet and translucent, and keep copy concise, reflective, and action-oriented.

The final desktop and mobile checks confirmed that the task form, course form, project form, review flow, and time-control layout remain legible at their target breakpoints. Task editing is intentionally available after creation to avoid overloading the quick-capture form. Project pages pair outcome-level milestones with project-scoped sub-tasks so users can distinguish delivery checkpoints from day-to-day execution work.

The GitHub Pages static preview uses the same calm lavender, deep-ink, and disciplined violet visual language as the product workspace. It presents the growth-system narrative, module map, and true-data principle while explicitly separating the static preview from the OAuth- and database-backed product runtime.
